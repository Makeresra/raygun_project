## 🇹🇷 Türkçe: Proje Detayları

### 📝 Proje Hakkında
Bu proje, **Call of Duty: Zombies** modunun efsanevi silahı **Ray Gun Mark 2**'nin çalışan bir replikasıdır. 3D yazıcı ile üretilen gövde, **Arduino Nano** mikrodenetleyicisi ile hayat bulmuştur.

Silah, oyundaki efektleri taklit eden **RGB LED** animasyonlarına ve **TP4056** modülü ile desteklenen şarj edilebilir Li-Po batarya sistemine sahiptir.

### ✨ Özellikler
* **Ateşleme Efekti:** Tetiğe basıldığında gerçekçi yeşil/mavi patlama (burst) animasyonu.
* **Bekleme Modu (Idle):** Ateş edilmediğinde silah "nefes alıp verir" (yavaşça yanıp sönen yeşil ışık).
* **Şarj Edilebilir:** USB Type-C veya Micro-USB ile şarj edilebilen dahili Li-Po batarya.
* **Güvenlik:** Ana güç anahtarı ve pil koruma devresi.

### 🛠️ Malzeme Listesi
* **Beyin:** Arduino Nano
* **Güç:** PX1300XP-40C Li-Po Batarya (veya 3.7V Lityum Pil)
* **Şarj:** TP4056 Şarj Modülü
* **Işık:** 3x RGB LED (Ortak Katot)
* **Kontrol:** 1x Tetik Butonu, 1x Açma/Kapama Anahtarı

## 🇬🇧 English: Project Details

### 📝 About the Project
This project is a fully functional replica of the legendary **Ray Gun Mark 2** from **Call of Duty: Zombies**. The 3D-printed shell is brought to life using an **Arduino Nano** microcontroller.

It features realistic **RGB LED** animations that mimic the in-game effects and a rechargeable Li-Po battery system managed by a **TP4056** module.

### ✨ Features
* **Firing Effect:** Realistic green/blue burst animation when the trigger is pulled.
* **Idle Mode:** Breathing animation (slowly pulsing green light) when not firing.
* **Rechargeable:** Built-in Li-Po battery chargeable via USB Type-C or Micro-USB.
* **Safety:** Dedicated main power switch and battery protection circuit.

### 🛠️ Hardware List
* **Microcontroller:** Arduino Nano
* **Power:** PX1300XP-40C Li-Po Battery (or any 3.7V LiPo)
* **Charging:** TP4056 Charging Module
* **Lighting:** 3x RGB LED (Common Cathode)
* **Controls:** 1x Tactile Button (Trigger), 1x Toggle Switch (Main Power)
